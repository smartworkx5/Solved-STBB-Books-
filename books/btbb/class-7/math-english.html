Sample solved questions

A rational number is a number that can be written as p/q, where p and q are integers and q is not zero. Whole numbers, integers, fractions and decimals are all rational numbers. On a number line , positive numbers lie to the right of 0 and negative numbers lie to the left of 0. Formula: Place value = digit x value of its place. The place of a digit tells its value: ones, tens, hundreds, thousands, ten thousands, and after the decimal point tenths, hundredths and thousandths. In this exercise: 1. Represent the following numbers on a number line.; 2. Find the place value of each digit from the following numbers.; 3. Find the place value of the indicated (underlined) digit in the following numbers. Worked Example: i. 87,364 Formula used: Place value = digit x value of its place. Step 1: 8 is in the ten thousands place = 8 x 10000 = 80000. Step 2: 7 is in the thousands place = 7 x 1000 = 7000. Step 3: 3 is in the hundreds place = 3 x 100 = 300. Step 4: 6 is in the tens place = 6 x 10 = 60. Step 5: 4 is in the ones place = 4 x 1 = 4. Answer: Place values: 80000, 7000, 300, 60, 4. Worked Example: iii. 2,385 Formula used: Place value = digit x value of its place. Step 1: 2 is in the thousands place = 2 x 1000 = 2000. Step 2: 3 is in the hundreds place = 3 x 100 = 300. Step 3: 8 is in the tens place = 8 x 10 = 80. Step 4: 5 is in the ones place = 5 x 1 = 5. Answer: Place values: 2000, 300, 80, 5. Worked Example: v. 680.984 Formula used: Place value = digit x value of its place. Step 1: 6 is in the hundreds place = 6 x 100 = 600. Step 2: 8 is in the tens place = 8 x 10 = 80. Step 3: 0 is in the ones place = 0 x 1 = 0. Step 4: 9 is in the tenths place = 9 x 1/10 = 0.9. Step 5: 8 is in the hundredths place = 8 x 1/100 = 0.08.

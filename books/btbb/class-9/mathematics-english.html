Sample solved questions

Every number that can be marked on a number line is a real number . Real numbers have two parts: rational numbers , which can be written as p/q where p and q are integers and q is not zero, and irrational numbers , which cannot be written as p/q, such as √2, √3 and pi. -2 -1 0 1 2 The number line Whole numbers, integers, fractions, terminating decimals and repeating decimals are all rational. The square root of a number that is not a perfect square is irrational. Key Points Commutative property: a + b = b + a and a x b = b x a. Changing the order does not change the result. Associative property: (a + b) + c = a + (b + c) and (a x b) x c = a x (b x c). Changing the grouping does not change the result. Distributive property: a(b + c) = ab + ac. Additive identity is 0 and multiplicative identity is 1: a + 0 = a and a x 1 = a. Additive inverse of a is -a, because a + (-a) = 0. Multiplicative inverse (reciprocal) of a is 1/a, because a x 1/a = 1. Trichotomy property: for any two real numbers a and b, exactly one is true: a < b, a = b or a > b. Transitive property: if a < b and b < c, then a < c. Adding or subtracting the same number on both sides of an inequality keeps the inequality true. Multiplying or dividing by a negative number reverses the inequality sign. Formula: a^m x a^n = a^(m + n) ; a^m / a^n = a^(m - n) ; (a^m)^n = a^(mn). Formula: a^0 = 1 ; a^(-n) = 1/a^n ; a^(1/n) = nth root of a. In a radical such as the nth root of x, the number under the root sign is the radicand and n is the index .

Sample MCQs with answers

  1. A number that can be written as p/q, where p and q are integers and q is not zero, is called a:

    Answer: Rational number

  2. Which of the following numbers is irrational?

    Answer: sqrt(3)

  3. Using the distributive property, 2 x (3 + 4) is equal to:

    Answer: 14

  4. Which statement shows the commutative property of addition?

    Answer: a + b = b + a

  5. The additive identity for real numbers is:

    Answer: 0

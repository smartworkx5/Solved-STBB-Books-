Learning Outcomes Students' learning outcomes (page 5): After completing this unit, students will be able to: count numbers up to and across 999 (3 digit numbers) forward and backward, beginning from zero or one or from any given number; read and write numbers up to 999 in numeral and up to 99 in words; recognize the place value of each digit in 3-digit numbers (hundred, tens, ones / unit); compare and order number up to 999 using appropriate language (for instance: more and less, greater, smaller, equal to, same as, increasing, decreasing, smallest to largest and vice versa etc.); round numbers to the nearest tens using different concrete objects and pictorial representation; recognize the position of objects and write it using ordinal numbers up to 20; read and write Roman numbers up to 12.

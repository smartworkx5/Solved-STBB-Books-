Sample solved questions

A rational number is a number that can be written in the form p/q, where p and q are integers and q is not zero. An irrational number cannot be written in the form p/q; its decimal goes on for ever without terminating and without repeating, for example the square root of 6 = 2.4494897... A terminating decimal has a finite (fixed) number of digits after the decimal point, like 0.657. A non-terminating decimal has infinite digits. A non-terminating decimal whose digits repeat in a pattern is a recurring decimal (1.777..., 2.3131...); one whose digits never repeat is non-recurring . Every recurring decimal is rational, and every non-recurring decimal is irrational. Formula: Absolute value |x| = distance of x from 0 on the number line. Distance is always positive, so |-25| = 25 and |14| = 14. In this exercise: 1. Separate rational and irrational numbers.; 2. Identify terminating and non-terminating decimal numbers.; 3. Represent each number on a number line.; 4. Find the absolute value of each number.; 5. Identify recurring and non-recurring decimal numbers.; 6-10. Word problems on real numbers. Worked Example: Q.6 — Maheen jogged 3.34 km. Ali jogged 2.45 times more distance than Maheen. Find the distance covered by Ali. Formula used: Distance of Ali = 2.45 x distance of Maheen. Step 1: Distance covered by Maheen = 3.34 km. Step 2: Multiply: 3.34 x 2.45 = 3.34 x 2 + 3.34 x 0.45. Step 3: 3.34 x 2 = 6.68 and 3.34 x 0.45 = 1.503, so the total is 6.68 + 1.503 = 8.183. Answer: Ali covered 8.183 km. Worked Example: Q.10 — Mahnoor bought 1/4 litre pineapple juice and 1 1/2 litre strawberry juice. How much juice did she buy?

Sample solved questions

Q1(i) Write in standard form and point out pure quadratic equations: (x + 7)(x - 3) = -7 Step 1: Expand the left side: (x + 7)(x - 3) = x^2 - 3x + 7x - 21 = x^2 + 4x - 21. Step 2: Bring all terms to the left: x^2 + 4x - 21 = -7, so x^2 + 4x - 21 + 7 = 0. Step 3: Standard form: x^2 + 4x - 14 = 0. Here a = 1, b = 4, c = -14. Since b is not 0, it is NOT a pure quadratic equation. Q1(ii) Write in standard form: (x^2 + 4)/3 - x/7 = 1 Step 1: Multiply every term by LCM(3, 7) = 21: 7(x^2 + 4) - 3x = 21. Step 2: Expand: 7x^2 + 28 - 3x = 21. Step 3: Bring all terms to the left: 7x^2 - 3x + 28 - 21 = 0. Step 4: Standard form: 7x^2 - 3x + 7 = 0. Here a = 7, b = -3, c = 7. Since b is not 0, it is NOT a pure quadratic equation. Q1(iii) Write in standard form: x/(x + 1) + (x + 1)/x = 6 Step 1: Take LCM x(x + 1): [x^2 + (x + 1)^2] / [x(x + 1)] = 6. Step 2: Cross-multiply: x^2 + x^2 + 2x + 1 = 6x(x + 1) = 6x^2 + 6x. Step 3: Bring all terms to one side: 0 = 6x^2 + 6x - 2x^2 - 2x - 1. Step 4: Standard form: 4x^2 + 4x - 1 = 0 (x not 0, -1). Here a = 4, b = 4, c = -1. Since b is not 0, it is NOT a pure quadratic equation. Q1(iv) Write in standard form: (x + 4)/(x - 2) - (x - 2)/x + 4 = 0 Step 1: Take LCM x(x - 2): x(x + 4) - (x - 2)^2 + 4x(x - 2) = 0. Step 2: Expand: x^2 + 4x - (x^2 - 4x + 4) + 4x^2 - 8x = 0. Step 3: Simplify: x^2 + 4x - x^2 + 4x - 4 + 4x^2 - 8x = 0, so 4x^2 + 0x - 4 = 0. Step 4: Standard form: 4x^2 - 4 = 0, i.e. x^2 - 1 = 0. Here a = 4, b = 0, c = -4. Since b = 0, it IS a pure quadratic equation. Q1(v) Write in standard form: (x + 3)/(x + 4) - (x - 5)/x = 1 Step 1: Take LCM x(x + 4): x(x + 3) - (x - 5)(x + 4) = x(x + 4). Sample MCQs with answers

What is the standard form of (x + 7)(x - 3) = -7?

Answer: x^2 + 4x - 14 = 0

The equation x^2 + 4x - 14 = 0 is NOT a pure quadratic equation because:

Answer: b = 4 is not zero

What is the standard form of (x^2 + 4)/3 - x/7 = 1?

Answer: 7x^2 - 3x + 7 = 0

Which of the following equations is a pure quadratic equation?

Answer: 4x^2 - 4 = 0

What is the standard form of (x + 3)/(x + 4) - (x - 5)/x = 1?

Answer: x^2 - 20 = 0

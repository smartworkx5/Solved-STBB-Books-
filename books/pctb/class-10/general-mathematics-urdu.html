اہم نکات کثیر رقمی P(x) کی کسی خاص قیمت پر قیمت معلوم کرنے کے لیے اس قیمت کو x کی جگہ رکھ کر حساب لگایا جاتا ہے۔ P(0) معلوم کرنے کے لیے x = 0 رکھا جاتا ہے، اس لیے x والی تمام رقوم صفر ہو جاتی ہیں اور صرف مستقل رقم باقی رہتی ہے۔ منفی قیمت رکھتے وقت قوسین کا استعمال ضروری ہے، کیونکہ جفت طاقت منفی عدد کو مثبت اور طاق طاقت اسے منفی رکھتی ہے۔ دائرے کے محیط کا فارمولا P(r) = 2πr ہے، جہاں r رداس ہے۔ کرے کے سطحی رقبے کا فارمولا P(r) = 4πr^2 ہے، جہاں r رداس ہے۔ ناطق کثیر رقمی میں مخرج صفر نہیں ہو سکتا، اس لیے قیمت رکھنے سے پہلے مخرج کا صفر نہ ہونا جانچنا چاہیے۔ حل شدہ سوالات و جوابات سوال: Q1 If P(x) = x^4 + 3x^2 - 5x + 9, تو معلوم کریں P(x) کے لیے x = 0 اور x = 1 حل: مرحلہ 1: P(0) = (0)^4 + 3(0)^2 - 5(0) + 9 = 0 + 0 - 0 + 9 = 9. مرحلہ 2: P(1) = (1)^4 + 3(1)^2 - 5(1) + 9 = 1 + 3 - 5 + 9 = 8. So P(0) = 9 اور P(1) = 8. سوال: Q2 If P(x) = 2x^3 + 2x^2 + x - 1, تو معلوم کریں P(-2) حل: مرحلہ 1: P(-2) = 2(-2)^3 + 2(-2)^2 + (-2) - 1. مرحلہ 2: = 2(-8) + 2(4) - 2 - 1 = -16 + 8 - 2 - 1. مرحلہ 3: = -11. سوال: Q3 If P(y) = 3y^2 + y/4 + 9, تو معلوم کریں P(0) حل: مرحلہ 1: P(0) = 3(0)^2 + (0)/4 + 9 = 0 + 0 + 9. مرحلہ 2: = 9. سوال: Q4 If P(x) = 9x^3 - 2x^2 + 3x + 1, تو معلوم کریں P(1) اور P(2) حل: مرحلہ 1: P(1) = 9(1) - 2(1) + 3(1) + 1 = 9 - 2 + 3 + 1 = 11. مرحلہ 2: P(2) = 9(8) - 2(4) + 3(2) + 1 = 72 - 8 + 6 + 1 = 71. So P(1) = 11 اور P(2) = 71. سوال: Q5 If P(x) = (x^2 - 5x + 6)/(x + 1), تو معلوم کریں P(1) اور P(2) حل: مرحلہ 1: P(1) = (1 - 5 + 6)/(1 + 1) = 2/2 = 1. مرحلہ 2: P(2) = (4 - 10 + 6)/(2 + 1) = 0/3 = 0. So P(1) = 1 اور P(2) = 0. سوال: Q6 If P(r) = 2 x pi x r, تو معلوم کریں P(r) کے لیے r = 3 اور pi = 22/7 حل: مرحلہ 1: P(3) = 2 x (22/7) x 3. مرحلہ 2: = 132/7 = 18.86 (تقریباً). سوال: Q7 If P(r) = 4 x pi x r^2, تو معلوم کریں P(r) کے لیے r = 8 اور pi = 22/7 حل: مرحلہ 1: P(8) = 4 x (22/7) x…

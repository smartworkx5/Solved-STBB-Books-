Sample solved questions

Q1. Given (a) f(x) = x2 - x and (b) f(x) = sqrt(x + 4), find (i) f(-2) (ii) f(0) (iii) f(x - 1) (iv) f(x2 + 4) Q1(a)(i). Find f(-2) for f(x) = x2 - x. f(x) = x2 - x. Put x = -2: f(-2) = (-2)2 - (-2). (-2)2 = 4 and -(-2) = +2. f(-2) = 4 + 2 = 6. Answer: f(-2) = 6. Q1(a)(ii). Find f(0) for f(x) = x2 - x. f(x) = x2 - x. Put x = 0: f(0) = (0)2 - 0. f(0) = 0 - 0 = 0. Answer: f(0) = 0. Q1(a)(iii). Find f(x - 1) for f(x) = x2 - x. f(x) = x2 - x. Replace x by (x - 1): f(x - 1) = (x - 1)2 - (x - 1). (x - 1)2 = x2 - 2x + 1. So f(x - 1) = x2 - 2x + 1 - x + 1. f(x - 1) = x2 - 3x + 2. Answer: f(x - 1) = x2 - 3x + 2. Q1(a)(iv). Find f(x2 + 4) for f(x) = x2 - x. f(x) = x2 - x. Replace x by (x2 + 4): f(x2 + 4) = (x2 + 4)2 - (x2 + 4). (x2 + 4)2 = x4 + 8x2 + 16. So f(x2 + 4) = x4 + 8x2 + 16 - x2 - 4. f(x2 + 4) = x4 + 7x2 + 12. Answer: f(x2 + 4) = x4 + 7x2 + 12. Q1(b)(i). Find f(-2) for f(x) = sqrt(x + 4). f(x) = sqrt(x + 4). Put x = -2: f(-2) = sqrt(-2 + 4). f(-2) = sqrt(2). Answer: f(-2) = sqrt(2). Q1(b)(ii). Find f(0) for f(x) = sqrt(x + 4). f(x) = sqrt(x + 4). Put x = 0: f(0) = sqrt(0 + 4). f(0) = sqrt(4) = 2. Answer: f(0) = 2. Q1(b)(iii). Find f(x - 1) for f(x) = sqrt(x + 4). f(x) = sqrt(x + 4). Replace x by (x - 1): f(x - 1) = sqrt((x - 1) + 4). f(x - 1) = sqrt(x + 3). Answer: f(x - 1) = sqrt(x + 3). Q1(b)(iv). Find f(x2 + 4) for f(x) = sqrt(x + 4). f(x) = sqrt(x + 4). Replace x by (x2 + 4): f(x2 + 4) = sqrt((x2 + 4) + 4). f(x2 + 4) = sqrt(x2 + 8). Answer: f(x2 + 4) = sqrt(x2 + 8). Q2. Find [f(a + h) - f(a)] / h and simplify Q2(i). For f(x) = 6x - 9, find [f(a + h) - f(a)] / h. f(x) = 6x - 9. f(a + h) = 6(a + h) - 9 = 6a + 6h - 9. f(a) = 6a - 9. f(a + h) - f(a) = (6a + 6h - 9) - (6a - 9) = 6h. Divide by h: 6h / h = 6. Answer: 6. Q2(ii). For f(x) = sin x, find [f(a + h) - f(a)] / h.…

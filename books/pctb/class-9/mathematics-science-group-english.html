Q1: Identify each of the following as a rational or irrational number (i) 2.353535 (ii) 0.6 (recurring) (iii) 2.236067... (iv) sqrt(7) (v) e (vi) pi (vii) 5 + sqrt(11) (viii) sqrt(3) + sqrt(13) (ix) 15/4 (x) (2 - sqrt(2))(2 + sqrt(2)) Rule: A number that can be written in the form p/q (p, q integers, q not 0) is rational. Terminating and non-terminating recurring decimals are rational; non-terminating non-recurring decimals are irrational. (i) 2.353535: it is a terminating decimal, so it can be written in p/q form. Hence it is a rational number. (ii) 0.666... is a non-terminating recurring decimal (6 repeats), so it is a rational number. (iii) 2.236067... is non-terminating and non-recurring, so it cannot be written in p/q form. Hence it is an irrational number. (iv) sqrt(7): 7 is not a perfect square, so sqrt(7) is non-terminating and non-recurring. Hence it is an irrational number. (v) e = 2.71828182845904... is non-terminating and non-recurring. Hence it is an irrational number. (vi) pi = 3.141592653589793... is non-terminating and non-recurring. Hence it is an irrational number. (vii) 5 + sqrt(11): sqrt(11) is irrational, and rational + irrational = irrational. Hence 5 + sqrt(11) is an irrational number. (viii) sqrt(3) + sqrt(13): both terms are irrational and their sum does not terminate or recur. Hence it is an irrational number. (ix) 15/4 is already in p/q form with q = 4 (not 0). Hence it is a rational number. (x) (2 - sqrt(2))(2 + sqrt(2)): Formula: (a - b)(a + b) = a^2 - b^2. Step 1: = (2)^2 - (sqrt(2))^2 Step 2: = 4 - 2 Step 3: = 2, which is in p/q form (2/1).

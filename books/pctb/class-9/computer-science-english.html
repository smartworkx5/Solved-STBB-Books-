Sample solved questions

The primary function of a system is to achieve a common goal . A fundamental concept of any system is its objective . A thermostat regulating temperature is an example of a simple system . A static environment remains unchanged unless the system provides an output. The basic components of a system are its objective, components, environment and communication . Systems theory aims to understand system interactions and their development over time . In a computer, the operating system receives input from the interface components and decides what to do with it. The main characteristic of the Von Neumann architecture is a single memory store for both program instructions and data. A disadvantage of the Von Neumann architecture is the bottleneck caused by the single memory space shared by instructions and data. The system bus transports data inside a computer among its different components.

    Answer: A simple system

    Answer: It remains unchanged unless the system provides an output

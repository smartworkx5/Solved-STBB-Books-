Sample solved questions

Question 1. Think! Give any five real life examples in which you use negative integers. Answer: Negative integers are used wherever a value is counted below a zero reference point. (i) Temperature below 0 <sup>o</sup>C in winter, for example -5 <sup>o</sup>C. (ii) Floors below ground level in a building, for example basement -1 and -2. (iii) Depth below sea level, for example a fish at -750 ft. (iv) Money owed or borrowed, for example a debt of Rs. 500 written as -500. (v) A drop in marks or points, for example losing 10 points written as -10. Question 2. Skill Practice: Solve the following: |-10|, |-17|, |19| and |-6|. Also arrange them in ascending and descending order. Step 1: The absolute value |x| is the distance of x from 0 on the number line, so it is never negative. Step 2: |-10| = 10, because -10 is 10 units away from 0. Step 3: |-17| = 17, because -17 is 17 units away from 0. Step 4: |19| = 19, because 19 is 19 units away from 0. Step 5: |-6| = 6, because -6 is 6 units away from 0. Step 6: Ascending order (smallest to largest): 6, 10, 17, 19. Step 7: Descending order (largest to smallest): 19, 17, 10, 6. Final answer: |-10| = 10, |-17| = 17, |19| = 19, |-6| = 6; ascending 6, 10, 17, 19; descending 19, 17, 10, 6. Question 3.

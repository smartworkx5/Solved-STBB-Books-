Sample solved questions

Q1. Identify which of the following fractions are terminating and which are recurring decimal fractions? Rule: First write each fraction in its lowest terms. If the denominator has only 2s and 5s as factors, the decimal terminates. If the denominator has any other prime factor, the decimal recurs (repeats). Terminating: (iv) 2/5 = 0.4; (viii) 6/10 = 3/5 = 0.6; (ix) 16/20 = 4/5 = 0.8; (x) 9/10 = 0.9; (xi) 1/8 = 0.125; (xii) 14/20 = 7/10 = 0.7; (xiv) 4/5 = 0.8; (xv) 1/4 = 0.25; (xvii) 8/10 = 4/5 = 0.8; (xviii) 3/5 = 0.6. Recurring: (i) 4/6 = 2/3 = 0.333...; (ii) 11/12, 12 = 2 × 2 × 3, so 0.9166...; (iii) 1/3 = 0.333...; (v) 8/11 = 0.7272...; (vi) 5/12 = 0.4166...; (vii) 5/7 = 0.714285...; (xiii) 2/3 = 0.666...; (xvi) 7/9 = 0.777.... Q2. Separate rational and irrational numbers from the following: Rational numbers can be written as p/q, or as terminating or recurring decimals. Irrational numbers cannot. Rational: (ii) 1/7; (iii) 2.152 (terminating); (iv) 0.818281828182... (the block 82 repeats, so recurring); (v) 2.751 (terminating); (vi) 22/7; (viii) √25 = 5. Irrational: (i) √5, because 5 is not a perfect square; (vii) √14, because 14 is not a perfect square. Q3. Sample MCQs with answers

What is 2/5 as a decimal, and is it terminating or recurring?

Answer: 0.4, terminating

In lowest terms, 4/6 is equal to which fraction, and what kind of decimal does it give?

Answer: 2/3, recurring (0.333...)

Which of the following numbers is irrational?

Answer: sqrt(5)

The decimal 0.818281828182... has the block 82 repeating. How is it classified?

Answer: Rational, because it is a recurring decimal

On a number line, 21/4 lies at which position?

Answer: 5.25, between 5 and 6, just to the right of 5

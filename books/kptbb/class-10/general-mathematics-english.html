Key Points A rational expression is p(x)/q(x) where p(x) and q(x) are polynomials and q(x) is not zero. Any polynomial can be written over 1, for example x + 1 = (x + 1)/1, so it behaves like a rational number. In a polynomial, the exponent of the variable in every term must be zero or a positive integer. Terms such as 3/x = 3x^(-1) or 1/x = x^(-1) have negative powers, so expressions containing them as written are not polynomials. A square root such as √(x + 1) = (x + 1)^(1/2) is not a polynomial because 1/2 is not a positive integer. The constant 2 is a rational expression because it can be written as 2/1, with 2 and 1 constant polynomials. The degree of a polynomial is the highest power of the variable in it. A non-zero constant such as 5 has degree 0, because 5 = 5x^0. Solved Exercises Q: Q1 (i). Which expressions behave like rational numbers? x + 1 Ans: A rational expression p(x)/q(x), q(x) not zero, behaves like a rational number. x + 1 can be written as (x + 1)/1, where x + 1 and 1 are polynomials. So x + 1 behaves like a rational number. Q: Q1 (ii). (x² + 1)/(x − 1) Ans: Here p(x) = x² + 1 and q(x) = x − 1 are both polynomials and q(x) is not zero. So (x² + 1)/(x − 1) is of the form p(x)/q(x). It behaves like a rational number. Q: Q1 (iii). x² + 3/x Ans: The term 3/x contains x with power −1. So x² + 3/x is not a polynomial, and the expression is not of the form p(x)/q(x) as written. It does not behave like a rational number. Q: Q1 (iv). (x² + 2x + 3)/(x² + 2) Ans: Here p(x) = x² + 2x + 3 and q(x) = x² + 2 are both polynomials and q(x) is not zero. Sample MCQs with answers

  1. Which expression behaves like a rational number?

    Answer: x + 1

  2. Does (x² + 1)/(x − 1) behave like a rational number?

    Answer: Yes, because both parts are polynomials and the denominator is not zero

  3. Why does x² + 3/x NOT behave like a rational number as written?

    Answer: Because 3/x contains x with power −1, so the whole expression is not a polynomial in the required form

  4. Which of these behaves like a rational number?

    Answer: (x² + 2x + 3)/(x² + 2)

  5. Which expression is a polynomial?

    Answer: x² + 2x + 3

Key Points A set is a collection of well-defined and distinct objects. Well-defined means we can clearly decide whether any given object belongs to the collection or not. The symbol ∈ means 'is a member of / belongs to'. A statement x ∈ A is correct only if x is actually listed in A. Here A = {4, 6, 8, 10, 12, 14}. In tabular form we list each element separated by a comma inside curly brackets { }, and the set is denoted by a capital letter. The elements of a set are distinct, so no element is repeated. In tabular form we list each distinct element separated by a comma inside curly brackets { }. Exercise 1.1 Q: Q1. State, giving reason, whether the following objects form a set or not: (i) All problems of this book, which are difficult to solve. (ii) All problems of this book, which are difficult to solve for Amjad. (iii) All the objects heavier than 26 kg. (iv) Students in a class-room. (v) Books in your school-bag. (vi) Counting numbers from 5 to 15. (vii) Students of your class, who are taller than you. Ans: Rule: A set is a collection of well-defined and distinct objects. Well-defined means we can clearly decide whether any given object belongs to the collection or not. (i) Not a set. Reason: The word 'difficult' is not well-defined. A problem that is difficult for one person may be easy for another, so we cannot clearly decide which problems are included. (ii) It is a set. Reason: Here the problems are difficult for one fixed person, Amjad. For Amjad the collection is definite, so we can decide which problems are included. (iii) It is a set. Reason: 'Heavier than 26 kg' can be checked exactly by weighing, so the objects are well-defined. (iv) It is a set. Sample MCQs with answers

Which collection is NOT a set?

Answer: All problems of this book, which are difficult to solve

Why is 'all problems of this book which are difficult to solve for Amjad' a set?

Answer: Because for one fixed person, Amjad, it is definite which problems are difficult for him

If A = {4, 6, 8, 10, 12, 14}, which statement is correct?

Answer: 12 ∈ A

What is the set of vowels in the English alphabet in tabular form?

Answer: {a, e, i, o, u}

Which set is infinite?

Answer: The set of whole numbers

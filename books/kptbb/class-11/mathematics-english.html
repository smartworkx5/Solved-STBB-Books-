Key Points Powers of i repeat every 4: i¹ = i, i² = −1, i³ = −i, i⁴ = 1; e.g. i⁹ + i¹⁹ = i + (−i) = 0. i¹⁰⁷ + i¹¹² + i¹²² + i¹⁵³ = (−i) + 1 + (−1) + i = 0. Complex numbers add and subtract part by part: real parts together and imaginary parts together. Multiplication uses (a + bi)(c + di) = (ac − bd) + (ad + bc)i with i² = −1; e.g. (11 + 8i)(−7 + 5i) = −117 − i. Division is done by multiplying numerator and denominator by the conjugate of the denominator; e.g. (4 + i)/(3 + 5i) = (1)/(2) − (1)/(2)i. For z = a + bi, |z| = √(a² + b²); for z₁ = 1 + 2i, z₂ = 2 + 3i: |z₁ + z₂| = √34 and |z₁z₂| = √65. |z₁/z₂| = |z₁|/|z₂| = (√65)/(13) for z₁ = 1 + 2i, z₂ = 2 + 3i (the book's printed value is the quotient itself, not its modulus). The conjugate is found after simplifying: ((3 − 2i)(2 + 3i))/((1 + 2i)(2 − i)) = (63)/(25) − (16)/(25)i, whose conjugate is (63)/(25) + (16)/(25)i. Solved Exercises Q: Q1(i). Simplify the following: i⁹ + i¹⁹ Ans: Rule: i¹ = i, i² = −1, i³ = −i, i⁴ = 1, and the powers of i repeat after every 4. i⁹ = i⁸ × i i⁹ = (i⁴)² × i = 1 × i = i i¹⁹ = i¹⁶ × i³ i¹⁹ = (i⁴)⁴ × i³ = 1 × (−i) = −i i⁹ + i¹⁹ = i + (−i) Answer: 0 Q: Q1(ii). Simplify the following: (−i)²³ Ans: Rule: (−i)²³ = (−1)²³ × i²³, and the powers of i repeat after every 4. (−i)²³ = (−1)²³ × i²³ (−1)²³ = −1 i²³ = i²⁰ × i³ = (i⁴)⁵ × i³ = 1 × (−i) = −i (−i)²³ = (−1) × (−i) Answer: i Q: Q1(iii). Simplify the following: (−1)^(−23/2) Ans: Rule: (−1)^(1/2) = i, so (−1)^(k/2) = iᵏ for any integer k. (−1)^(−23/2) = i⁻²³ i⁻²³ = (1)/(i²³) i²³ = i²⁰ × i³ = (i⁴)⁵ × (−i) = −i i⁻²³ = (1)/(−i) Multiply numerator and denominator by i: (1)/(−i) = (i)/(−i²) = (i)/(1) Answer: i Q: Q1(iv).

Key Points Expanded form writes a number as the sum of the place values of its digits. Standard form is the ordinary number obtained by adding all the place value parts. The place value of a digit is the digit multiplied by the value of its place. Exercise 1 (Questions 1–23) Q: a) Write the following number in expanded form: 675,432 Ans: Rule: Expanded form writes a number as the sum of the place values of its digits. 6 is in the hundred thousands place, so its value is 6 x 100,000 = 600,000. 7 is in the ten thousands place, so its value is 7 x 10,000 = 70,000. 5 is in the thousands place, so its value is 5 x 1,000 = 5,000. 4 is in the hundreds place, so its value is 4 x 100 = 400. 3 is in the tens place, so its value is 3 x 10 = 30. 2 is in the ones place, so its value is 2 x 1 = 2.

Sample solved questions

Key Ideas A rational number can be written in p/q form, where p and q are integers and q is not zero. Every integer, terminating decimal and repeating decimal is rational. An irrational number cannot be written in p/q form. Its decimal form never terminates and never repeats. Between any two different real numbers there are infinitely many real numbers, so all real numbers between 1 and 2 can never be listed completely. Formulas Rational number = p/q, q != 0 Q union Q' = R pi = 3.14159... Example: Identify rational and irrational numbers Step 1: Check 1/5. It is already in p/q form, so it is rational. Step 2: Check sqrt(8). Write sqrt(8) = sqrt(4 x 2) = 2sqrt(2). Since sqrt(2) is irrational, sqrt(8) is irrational. Step 3: Check 0. Write 0 = 0/1, which is p/q form, so 0 is rational. Step 4: Check 1/sqrt(3). The denominator contains sqrt(3), which is irrational, so 1/sqrt(3) is irrational. Example: Terminating or non-terminating decimal Step 1: Take 5/8 and divide 5 by 8. 5/8 = 0.625 Step 2: The division ends after three decimal places, so it is terminating. Step 3: Take 4/18. Simplify: 4/18 = 2/9. 2/9 = 0.222... = 0.2 bar Step 4: The digit 2 keeps repeating and never ends, so it is non-terminating and repeating, hence rational. Example: Represent 1 1/4 on the number line Step 1: Convert the mixed number: 1 1/4 = 5/4 = 1.25. Step 2: Look between 1 and 2 on the number line. Step 3: Divide that unit into 4 equal parts. Step 4: The first mark after 1 is 1.25, which is 1 1/4.

Sample MCQs with answers

  1. Which of the following is a rational number?

    Answer: 1/5

  2. sqrt(8) is irrational because:

    Answer: sqrt(8) = 2sqrt(2) and sqrt(2) is irrational

  3. The decimal form of 5/8 is:

    Answer: 0.625

  4. 4/18 in decimal form is:

    Answer: 0.222... repeating

  5. Why is pi an irrational number?

    Answer: Its decimal never terminates and never repeats

Sample solved questions

Maple: A Symbolic Package Maple works with symbols such as x and y exactly. Its commands here are expand, factor, simplify and evalf, with matrix and plot commands. The expand Command The expand command multiplies out products and powers, using: (x + y)^3 = x^3 + 3x^2 y + 3x y^2 + y^3 (p + q)^2 = p^2 + 2pq + q^2 and (p - q)^2 = p^2 - 2pq + q^2 It also uses cos(x + y) = cos x cos y - sin x sin y and sin(x - y) = sin x cos y - cos x sin y. A single radical such as sqrt(x + y) has nothing to distribute over it, so expand returns it unchanged. The factor Command The factor command reverses expand, writing an expression as a product of factors. First take out any common factor, then use: a^2 - b^2 = (a - b)(a + b) and a^3 - b^3 = (a - b)(a^2 + ab + b^2) For example, x^2 - 4 = (x - 2)(x + 2) and x^2 + 4x + 4 = (x + 2)^2. A quadratic is factored by splitting its middle term and grouping. The simplify and evalf Commands Simplify cancels a common factor of numerator and denominator, as in (x + 1)^2 / (x + 1) = x + 1, allowed when x is not equal to -1; with no common factor, a fraction is already simplest. It also uses: sin^2 x + cos^2 x = 1 The evalf command converts an exact value into a decimal. Matrix and Plot Commands Matrix(2, [1, 2, 3, 4]) is filled row by row. Transpose turns rows into columns: the 2 by 3 matrix with rows 1, 2, 3 and 4, 5, 6 becomes the 3 by 2 matrix with rows 1, 4 and 2, 5 and 3, 6. Matrix Inverse works when the determinant is not zero: for a 2 by 2 matrix, swap the diagonal entries, change the signs of the off-diagonal entries, and divide every entry by the determinant. Sample MCQs with answers

  1. In Maple, what does expand give for (x + y)^3?

    Answer: x^3 + 3x^2y + 3xy^2 + y^3

  2. In Maple, expand (2a - b)^2 + (a + 3b)^2 equals:

    Answer: 5a^2 + 2ab + 10b^2

  3. What does the Maple factor command give for x^3 - 8?

    Answer: (x - 2)(x^2 + 2x + 4)

  4. In Maple, factor of 3x^3 + 12x^2 - 15x is:

    Answer: 3x(x + 5)(x - 1)

  5. In Maple, simplify of (x + 1)^2 / (x + 1), for x not equal to -1, is:

    Answer: x + 1

Sample solved questions

تصور سيٽ مان مراد اهڙي گڏجاڻي آهي جنهن جا رڪن صاف صاف سمجهي سگهجن. رڪنن کي وڏين قوسين { } جي اندر لکبو آهي ۽ هر رڪن هڪ ئي ڀيرو لکبو آهي. سيٽ کي لکڻ جو هڪ طريقو بياني نمونو آهي. بياني نموني ۾ رڪنن کي لفظن ۾ بيان ڪبو آهي، جيئن عدد 3 جا پهريان چار ضرب يا انگريزي الفابيٽ جا علت وارا حرف. ٻيو طريقو علامتي نمونو آهي. ان ۾ شرط لکبي آهي ته رڪن ڪهڙي قسم جا آهن ۽ ڪهڙي حد ۾ آهن. D = {3, 6, 9, 12} مٿيون سيٽ 3 جا پهريان چار ضرب ڏيکاري ٿو، تنهنڪري ان جو بياني نمونو آهي: D = عدد 3 جي پهرين چئن ضربن جو سيٽ. مثال سوال: هيٺين سيٽ کي بياني نموني ۾ لکو. O = {a, e, i, o, u} قدم 1: سيٽ جا رڪن ڏسو: a, e, i, o, u قدم 2: اهي سڀ انگريزي الفابيٽ جا علت وارا حرف آهن. O = set of vowels of English alphabet جواب: O = انگريزي الفابيٽ جي علت وارن حرفن جو سيٽ. ياد رکو سيٽ جا رڪن { } جي اندر لکبا آهن. هر رڪن سيٽ ۾ هڪ ئي ڀيرو لکبو آهي. بياني نموني ۾ رڪنن جي خاصيت لفظن ۾ بيان ڪبي آهي. علامتي نموني ۾ شرط {x / x ∈ ...} جي نموني ۾ لکبي آهي. W = {0, 1, 2, 3, 4, 5, 6, 7, 8} کي 8 تائين مڪمل عددن جو سيٽ چئبو آهي.

Sample MCQs with answers

سيٽ D = {3, 6, 9, 12} جو بياني نمونو ڇا آهي؟

Answer: عدد 3 جي پهرين چئن ضربن جو سيٽ

سيٽ O = {a, e, i, o, u} بياني نموني ۾ ڇا سڏبو؟

Answer: انگريزي الفابيٽ جي علت وارن حرفن جو سيٽ

سيٽ W = {0, 1, 2, 3, 4, 5, 6, 7, 8} جو بياني نمونو ڪهڙو آهي؟

Answer: 8 تائين مڪمل يا پورن عددن جو سيٽ

سيٽ M = {مارچ، مئي} جو بياني نمونو ڇا آهي؟

Answer: ’م‘ سان شروع ٿيندڙ سال جي مهينن جي نالن جو سيٽ

لفظ ”خوبصورت“ جي اکرن جو سيٽ ڪهڙو آهي؟

Answer: B = {ت، ر، ص، ب، و، خ}

Sample solved questions

The Main Idea A set is a collection of well-defined objects. The objects in a set are called its members or elements. In this work you learn to look at the members in curly brackets { } and say in words what the set is. That is the descriptive form. You also learn the short set-builder form, which uses a rule with x. Formula / Rule Descriptive form = the set described in words, e.g. D = the set of the first four multiples of 3. Set-builder form = {x / x ∈ N} reads as: the set of all x such that x belongs to N. Symbols: N = natural numbers, W = whole numbers, Z = integers, E = even numbers, O = odd numbers. Worked Example Example: Write D = {3, 6, 9, 12} in descriptive form, and give the set-builder form of {1, 3, 5, 7, 9}. Step 1: Look at 3, 6, 9, 12. Each number is 3 × 1, 3 × 2, 3 × 3, 3 × 4. Step 2: So they are the first four multiples of 3. Step 3: Descriptive form: D = the set of the first four multiples of the number 3. Step 4: 1, 3, 5, 7, 9 are odd numbers from 1 to 9. Step 5: Set-builder form: {x / x ∈ O, 1 ≤ x ≤ 9}. Remember O = {a, e, i, o, u} is the set of vowels of the English alphabet. W = {0, 1, 2, 3, 4, 5, 6, 7, 8} is the set of whole numbers up to 8. M = {March, May} is the set of months whose names begin with M. The first five even numbers 2, 4, 6, 8, 10 are written as {x / x ∈ E ∧ 2 ≤ x ≤ 10}. All natural numbers are written as {x / x ∈ N}.

Sample MCQs with answers

What is the descriptive form of D = {3, 6, 9, 12}?

Answer: The set of the first four multiples of 3

O = {a, e, i, o, u} is the set of what?

Answer: Vowels of the English alphabet

W = {0, 1, 2, 3, 4, 5, 6, 7, 8} in descriptive form is:

Answer: The set of whole numbers up to 8

M = {March, May} is best described as:

Answer: The set of months of the year beginning with M

The set-builder form of the first five even numbers is:

Answer: {x / x ∈ E ∧ 2 ≤ x ≤ 10}

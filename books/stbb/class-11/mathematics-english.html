The Imaginary Unit and Powers of i A complex number is written as z = a + ib or as the ordered pair (a, b), where a is the real part and b is the imaginary part. The imaginary unit i = sqrt(-1) satisfies: i^2 = -1 The powers of i repeat in a cycle of 4: Power i^1 i^2 i^3 i^4 Value i -1 -i 1 To evaluate a higher power, remove multiples of 4 from the exponent. Also (-i)^2 = -1 and (-i)^4 = 1. Within 1 <= n <= 4, i^n equals i when n = 1, -1 when n = 2, -i when n = 3 and 1 when n = 4, and i^n + i^(n+1) + i^(n+2) + i^(n+3) = 0 for all n in Z. Operations on Complex Numbers Addition and subtraction are done by grouping the real parts together and the imaginary parts together. Multiplication is done term by term, replacing i^2 by -1. For ordered pairs: (a, b)(c, d) = (ac - bd, ad + bc) Division is done by multiplying the numerator and denominator by the conjugate of the denominator, because (c + di)(c - di) = c^2 + d^2 is real. Powers are simplified by first finding the square, for example (1 + i)^2 = 2i, and then multiplying on. Conjugate, Absolute Value and the Complex Plane The conjugate of z = a + ib is z-bar = a - ib: only the sign of the imaginary part is reversed. The absolute value (modulus) is: |z| = sqrt(a^2 + b^2) On the complex plane (Argand diagram) the real part is measured along the horizontal real axis and the imaginary part along the vertical imaginary axis. The point (a, b) represents z, and the length of the vector from the origin to that point is |z|. To solve a complex equation, write both sides in a + ib form and equate the real parts and the imaginary parts separately. Worked Example: Powers of i Example: Evaluate i^10 . Sample MCQs with answers

  1. What is the value of i^10 . (-i^12)?

    Answer: 1

  2. What is the value of (-i)^16 . (-i)^6?

    Answer: -1

  3. For any integer n, what is i^n + i^(n+1) + i^(n+2) + i^(n+3)?

    Answer: 0

  4. Using (a, b)(c, d) = (ac - bd, ad + bc), what is (-6, 3) . (4, -2)?

    Answer: (-18, 24)

  5. What is (2, 3) / (4, 5) as an ordered pair?

    Answer: (23/41, 2/41)

Sample solved questions

What is a Set? A well-defined collection of objects is called a set. Each object of a set is called its member (element). Sets are denoted by capital letters such as A, B, C. Tabular Form and Set-Builder Form In tabular form all the members are written inside curly brackets, such as A = {1, 2, 3}. In set-builder (symbolic) form the property of the members is written. A = {x | x ∈ N ∧ x < 4} = {1, 2, 3} Here ∈ means: is a member of. N is used for natural numbers, Z for integers, Q for rational numbers, R for real numbers, P for prime numbers and O for odd numbers. Empty Set, Singleton Set and Equal Sets A set which has no member is called an empty set and is denoted by ∅. A set which has only one member is called a singleton set. If two sets have exactly the same members, they are equal sets. Finite and Infinite Sets A set whose members can be counted and come to an end is called a finite set. A set whose members never come to an end is called an infinite set, such as the set of all prime numbers. Subset and Equivalent Sets If every member of A is also in B, then A is called a subset of B. A ⊆ B If A is a subset of B but A ≠ B, then it is a proper subset. Every set is an improper subset of itself. If two sets have the same number of members, they are equivalent sets. Power Set The set of all the subsets of a set is called its power set. If a set has n members, then the number of subsets in its power set is as follows. Number of subsets = 2^n Worked Example: Tabular Form Example: Write the set E = {z | z ∈ R ∧ z² = 121} in tabular form. Step 1: The condition is that z² = 121. Step 2: 11² = 121, so z = 11 is possible. Step 3: (-11)² = 121 also, so z = -11 is also possible. Step 4: Both values satisfy the condition. Step 5: So E = {-11, 11}. Worked Example: Power Set…

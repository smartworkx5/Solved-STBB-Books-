Sample solved questions

What this practice is about A set is a well-defined collection of objects. The objects in a set are called its members or elements. In this practical work we use the two membership symbols, write sets in tabular (roster) form, and sort sets into finite and infinite. The membership symbols The symbol ∈ means "is a member of" and the symbol ∉ means "is not a member of". 4 ∈ A and 9 ∉ A for A = {2, 4, 6, 8, 10} Tabular (roster) form In tabular form we list all the members inside curly brackets { }, separated by commas. Each member is written only once. Finite and infinite sets A set whose members can be counted (limited number) is a finite set . A set whose members never end (unlimited number) is an infinite set . An empty set has no members, a singleton set has exactly one member, equal sets have exactly the same members, equivalent sets have the same number of members, and a subset has all its members inside another set. Worked example (from Practical Work 2) Write in tabular form: the set of the first five natural numbers. Step 1: The first five natural numbers are 1, 2, 3, 4, 5. Step 2: List them inside curly brackets, separated by commas. Answer: {1, 2, 3, 4, 5}

For A = {2, 4, 6, 8, 10}, which statement is correct?

Answer: 6 ∈ A

For A = {2, 4, 6, 8, 10}, which of these is true?

Answer: 2 ∈ A

The set of the first five letters of the English alphabet in tabular form is:

Answer: {a, b, c, d, e}

In tabular form, the set of the first five natural numbers is:

Answer: {1, 2, 3, 4, 5}

The set of all residents of Pakistan is a:

Answer: Finite set

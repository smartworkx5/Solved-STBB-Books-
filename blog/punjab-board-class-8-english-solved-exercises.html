Punjab Class 8 English Solved Exercises

By Tasleem Sanjrani · SolvedBooks.pk · 636 words · 3 min read

515Solved Exercises

Class 8 English tests more than memory — the paper asks you to understand a passage, use grammar correctly and write clearly. Students who only memorise the exercise answers struggle with the unseen passage and the writing tasks. This guide shows how to use the solved exercises to build real English that works in the paper.

Master the passage before the questions

Open the Class 8 English book page and read each lesson's passage slowly, looking up every word you do not know. Answer the comprehension questions in your own words first, then compare with the solved answers — the comparison shows what you understood and what you missed.

Practise unseen passages the same way: read twice, underline the main idea of each paragraph, then answer. The paper's unseen passage works exactly like the book's passages once you have this habit.

Fix grammar with written practice

Tenses, voice, direct and indirect speech and punctuation are tested through sentences you must correct or complete. For each grammar topic, work the solved exercises in writing and mark every mistake — then write the correct sentence again. A mistake corrected in writing is rarely repeated.

Keep a grammar error list: the rule, your wrong sentence, and the corrected sentence. Revise it before every test. Most students repeat the same five or six mistakes — your list tells you which ones are yours.

Build writing step by step

Essays, letters, applications and stories are built from the same blocks: a clear opening, organised points, and a proper ending. Study one model answer from the solved exercises each week, note its structure, then write a similar piece on a different topic using the same structure.

Learn the formats by heart — a letter's address and greeting, an application's subject line, a story's opening. Format marks are free marks, but only if the format is exact. Write each format from memory once a week until it is automatic.

Revise with the notes and MCQs

In the final weeks, revise the chapter notes on the Notes page — one lesson a day, grammar error list open beside you — and test yourself with the solved exercises and the book closed. Whatever you cannot answer goes into a short revision list for the last days.

Finish with the MCQs practice page. Choose the Class 8 English book and practise with the correct answer and explanation shown for every question — it catches the grammar and vocabulary points that long-answer revision misses.

5 key points you must know

  • Answer comprehension questions in your own words before checking the solution.
  • Keep a grammar error list with the rule, the wrong sentence and the correction.
  • Study one model writing answer a week and copy its structure on a new topic.
  • Learn letter and application formats by heart until they are automatic.
  • Revise one lesson a day in the final weeks and test yourself with the book closed.

Frequently asked questions

Where can I find Punjab Board Class 8 English solved exercises?

On the Class 8 English book page. The solved exercises are free to read lesson by lesson, with notes on the Notes page.

How do I prepare for the Class 8 English paper?

Master each passage, fix grammar with written practice, build writing step by step, and test yourself with the solved exercises and MCQs.

How do I handle the unseen passage in Class 8 English?

Read it twice, underline the main idea of each paragraph, then answer in your own words. Practising the book's passages the same way builds exactly this skill.

Can I practise Class 8 English MCQs online?

Yes, on the MCQs practice page. Choose the Class 8 English book and practise with the correct answer and explanation shown for every question.
